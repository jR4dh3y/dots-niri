🚀 HOW TO USE
═══════════════════════════════════════════════════════════════════════════

OPTION 1: CSS APPLICATIONS (Waybar, Wlogout)
──────────────────────────────────────────────

In your CSS files, change:
  FROM: @import url("../themes/global-colors.css");
  TO:   @import url("../themes/nonchalant-purp.css");

Example for Waybar (~/.config/waybar/style.css):
  @import url("../themes/nonchalant-purp.css");
  
  window#waybar {
      background: @bg_color;
      color: @fg_color;
  }
  
  #workspaces button.focused {
      background: @accent_color;
  }


OPTION 2: SHELL SCRIPTS
──────────────────────────

Source the variables:
  source ~/.config/themes/colors-nonchalant-purp.sh

Use in scripts:
  notify-send "Colors" "BG: $COLOR_BG | Accent: $COLOR_ACCENT"
  echo "Main color: $COLOR_FG"


OPTION 3: CONFIG FILES (Kitty, Hyprland, Dunst, etc.)
──────────────────────────

Replace hex values directly:
  # Nonchalant Purp colors
  background = #1e1e20
  foreground = #dcd9e7
  accent = #c59edc


OPTION 4: KITTY TERMINAL
──────────────────────────

In ~/.config/kitty/kitty.conf:
  include nonchalant-purp-kitty.conf
